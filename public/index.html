CAPRAE SYSTEM DESIGN & ARCHITECTURE

Full Stack Architecture, Data Storage & Cloud Deployment

Production engineering blueprint designed for high-concurrency scraping, sub-50ms caching, and scalable AI inference.

1. Data Storage & Schema Design

Primary Database: PostgreSQL 16 on AWS Aurora Serverless / Supabase.

Entity Modeling: Normalized tables for Companies, DecisionMakers, TechSignatures, OutreachCampaigns, and AuditLogs.

Indexes: B-Tree indexing on domain (unique), icp_score (desc), and GIN full-text index on tech_stack and industry for sub-10ms querying across millions of B2B records.

2. Caching & Performance Optimizations

Caching Layer: Distributed Redis (AWS ElastiCache) with LRU eviction and 7-day TTL on domain DOM metadata.

Connection Pooling: Prisma / PgBouncer pool sizing preventing connection exhaustion under burst loads.

Scraping Throughput: Asynchronous worker queue (BullMQ + Redis) with concurrent proxy rotation, anti-fingerprinting User-Agent pools, and adaptive backoff.

3. Hosting & Cloud Provider Architecture

Cloud Provider: AWS (Amazon Web Services) & GCP hybrid-ready.

Backend API: Containerized Docker services running on AWS ECS (Elastic Container Service) with AWS Fargate serverless auto-scaling.

Edge CDN / Frontend: AWS CloudFront / Vercel Edge Network delivering cached static assets globally with TLS 1.3 & HTTP/3.

4. Security, Compliance & Rate-Limiting

Ethical Scraping: Full adherence to robots.txt parsing, strict domain request rate-limiting (Token Bucket algorithm: max 5 req/sec/domain).

Verification: MX record DNS lookup + syntax validator avoiding honeypots and spam traps.

API Gateway: JWT-based authorization, rate-limiting, and webhook signature verification (HMAC-SHA256).
